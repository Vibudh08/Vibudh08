### 🎟️ Eventora
Full-stack event booking platform with **React, Node.js, Express, MongoDB, JWT, Razorpay and Nodemailer**. Includes event discovery, search/filtering, seat tracking, bookings, cancellations, payment flows, email notifications, and user/admin dashboards.

### 💬 Feedback Fusion
Full-stack feedback management platform built with **Next.js, TypeScript, Prisma, PostgreSQL and Clerk**. Supports feedback submission, voting, comments, category filtering, roadmap tracking, and role-based status management.

### ✅ Taskflow
Production-oriented task management dashboard using **Next.js, TypeScript, MongoDB, TanStack Query, Zustand, Zod and JWT** with protected routes, refresh sessions, search, filters, pagination, dashboard metrics, and optimistic UI updates.

### 🤖 Nexora Digital
AI-powered marketing agency platform built with **Next.js, TypeScript and MongoDB**, featuring lead capture, Razorpay consultation payments, a hybrid **Gemini AI chatbot**, automated emails, admin lead management, technical SEO, and performance-focused architecture.
